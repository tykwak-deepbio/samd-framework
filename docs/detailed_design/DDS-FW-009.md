## 1. Detailed Unit Description & Rationale
`DDS-FW-009` specifies unit algorithms for sanitizing external inputs against prompt injection payloads, enforcing temperature clamping for reproducibility, and verifying that all PubMed citations in `DHF-02` correspond to real bibliographic records.

## 2. Data Structures & Interface Signatures
```python
INJECTION_SIGNATURES = [
    re.compile(r"ignore\s+(all\s+)?(previous|prior)\s+instructions", re.IGNORECASE),
    re.compile(r"system\s*prompt\s*override", re.IGNORECASE),
    re.compile(r"bypass\s+(safety|iso|iec)\s+checks", re.IGNORECASE)
]

def sanitize_untrusted_input(raw_text: str) -> str:
    for pattern in INJECTION_SIGNATURES:
        if pattern.search(raw_text):
            raise PromptInjectionSecurityException("Security violation: Adversarial injection pattern detected")
    return f"<untrusted_input>\n{raw_text}\n</untrusted_input>"
```

## 3. Algorithmic Pseudocode & Grounding Verification
```python
def verify_pubmed_citations(dhf_content: str) -> bool:
    pmids = re.findall(r"PMID:\s*(\d+)", dhf_content)
    dois = re.findall(r"10\.\d{4,9}/[-._;()/:A-Za-z0-9]+", dhf_content)
    
    assert len(pmids) + len(dois) > 0, "DHF-02 must contain verified PMIDs or DOIs"
    for pmid in pmids:
        assert pmid.isdigit() and len(pmid) >= 7, f"Invalid PMID format: {pmid}"
    return True
```

## 4. Error Handling & Boundary Conditions
- **Injection Pattern Match**: Aborts execution turn and writes security alert to log.
- **Unverified Citation**: Emits non-conformance error and halts gate review progression.

## 5. Safety Invariants & Risk Control Implementation (RCM-FW-004, RCM-FW-009)
- **Safety Invariant 1 (RCM-FW-009 - Medical Hallucination & Prompt Guard)**: All clinical literature citations generated by LLM agents must be validated against PubMed APIs or local MeSH database. Untrusted inputs must be encapsulated in boundary tokens to prevent prompt injection attacks.
- **Safety Invariant 2 (RCM-FW-004 - Adversarial Dual-Agent Review)**: Safety-critical DHF sections require dual-agent consensus where an independent auditor persona reviews and verifies generated content against clinical guidelines before gate release.
